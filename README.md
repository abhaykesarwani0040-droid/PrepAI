# PrepAI — AI-Powered Mock Interview Platform

PrepAI is a full-stack web application that helps students and job seekers practice interviews with AI-generated questions and feedback.

## Features
- User registration and login
- AI-powered interview question generation
- Answer evaluation and feedback
- Interview practice workflow

## Tech Stack
- React.js and Vite
- Node.js and Express.js
- MongoDB and Mongoose
- Google Gemini API
- JWT and bcrypt

## Run Locally

### Backend
```bash
cd backend
npm install
npm run dev
```

### Frontend
Open another terminal:
```bash
cd frontend
npm install
npm run dev
```

Configure the required environment variables in your backend `.env` file. Never commit API keys or database credentials.
